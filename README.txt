Chennai Waterlogging Dashboard (static site)
Files: index.html, manifest.webmanifest, sw.js, icons/
Host the folder contents at the site root over HTTPS (see hosting steps).
Edit data by hand in index.html: warnings, timeline, rainfall (var d=[...]) and the hotspots table.
Optional: set REPORT_PHONE near the bottom of index.html to receive WhatsApp reports.
